# Security policy

KythOS Kernal follows Debian 13 security updates while the raw base is in
development. No production release is supported yet.

Do not publish a suspected vulnerability before maintainers have had a chance
to investigate it. Use GitHub's private vulnerability reporting for the
`matthewalexandern/Kernal` repository when it is enabled. Until then, open a
repository issue containing no exploit, secret, personal data, or sensitive
machine details and request a private contact channel.

Include the KythOS version, Debian version, affected package, reproduction
conditions, and whether Secure Boot was enabled. Never include credentials,
private keys, or proprietary model data.
